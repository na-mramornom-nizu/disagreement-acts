# Акты разногласий

Веб-сервис подготовки PDF для Ингосстраха, АльфаСтрахования и РЕСО-Гарантии.

Публикация: https://boronind9-gmail-com.sourcecraft.site/disagreement-acts/

## Возможности

- Выбор компании и форма с полями соответствующего бланка.
- Дата по умолчанию — текущая, её можно изменить.
- Взаимный расчёт сумм: введите любые две из трёх — по счёту, вычет, к оплате. Выберите рассчитываемое поле над суммами.
- В АльфаСтраховании сумма по счёту повторяется в стоимости восстановительного ремонта, вычет — в итоге второй таблицы и нижнем блоке.
- Строки таблиц очищены. Незаданные поля остаются пустыми, ноль сохраняется как ноль.
- Предпросмотр с увеличением, скачивание PDF и печать того же файла.
- Раздельные черновики компаний в памяти вкладки, без отправки введённых данных на сервер.
- Адаптивный интерфейс, управление с клавиатуры, поддержка уменьшения анимации.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm test
npm run build
npm run dev
```

Откройте http://127.0.0.1:4194/disagreement-acts/.

Готовый `dist/index.html` содержит код, шрифты и шаблоны. Его можно разместить на статическом хостинге. Внешние API, база данных и CDN не используются. Для SourceCraft Sites файл размещается в корне репозитория, `.sourcecraft/sites.yaml` содержит:

```yaml
site:
  ref: main
```

## Работа с документом

1. Выберите компанию.
2. Заполните реквизиты. Над суммами укажите, что вычислить, и введите две остальные суммы.
3. Нажмите «Проверить документ». При необходимости увеличьте масштаб или вернитесь к редактированию.
4. Нажмите «Скачать PDF» или «Печать». Если браузер не показывает окно печати встроенного PDF, откройте предложенную ссылку на PDF и используйте значок принтера.

Данные сохраняются только до закрытия или обновления страницы. Переключение между компаниями их не удаляет. Кнопка «Очистить» требует подтверждения.

## Бланки

Шаблоны подготовлены по предоставленным пользователем образцам. Excel-бланки переведены в векторную геометрию PDF с сохранением состава таблиц; поля Ингосстраха адаптированы для длинных реквизитов и крупных сумм. В PDF АльфаСтрахования окончательно удалены прежние клиентские значения и строки таблиц, включая текстовый слой. Подпись, печать, данные эксперта и постоянные реквизиты в этом образце сохранены по прямому указанию заказчика. Исходные заполненные документы в репозиторий не включены. Это сервис заполнения предоставленных форм, а не официальный сайт страховых компаний.

Суммы рассчитываются целыми копейками. Допустимы точка или запятая, пробелы между разрядами, не более двух десятичных знаков. Диапазон — от 0 до 999 999 999,99. Слишком длинный текст, который невозможно разместить в поле, требует сокращения; молчаливое обрезание не применяется.

## Проверки

```sh
npm test
node tests/print-matrix.mjs
```

Вторая команда формирует 30 PDF-сценариев в локальной папке `output/print-matrix`: три компании, разные суммы, пустые бланки, даты, длинные значения, все направления расчёта. Тестовые файлы и отчёты исключены из Git.

Код: `src/model.mjs` — данные и расчёты; `src/document.mjs` — общая геометрия предпросмотра и PDF; `src/app.mjs` — интерфейс. Шрифты Liberation распространяются на условиях лицензии в `assets/LICENSE_LIBERATION.txt`. Условия зависимостей перечислены в `THIRD_PARTY_NOTICES.txt`. Права на предоставленные бланки, подпись, печать и обозначения компаний принадлежат их правообладателям.
